# Gestion des tâches (Python)

Application console très simple pour gérer des tâches quotidiennes.

## Fonctionnalités
- Ajouter une tâche (titre non vide)
- Afficher les tâches numérotées
- Rechercher une tâche par mot-clé
- Quitter

## Exécution
1. Ouvrir le dossier dans VS Code.
2. Ouvrir `main.py`.
3. Cliquer sur le bouton **Run Python File**.
